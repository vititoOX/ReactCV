# CV de Victor Perez Sosa

CV editable creado con React, Vite, html2canvas y jsPDF.

## Uso

```bash
npm install
npm run dev
```

Abre la URL que muestra Vite y pulsa **Descargar PDF**.

## Editar el contenido

Todos los datos del CV estan centralizados en `src/data.js`:

- datos de contacto y resumen;
- tecnologias;
- proyectos;
- experiencia y educacion.

La maquetacion vive en `src/main.jsx` y `src/styles.css`. La foto esta en `src/assets/victor.jpeg`.
